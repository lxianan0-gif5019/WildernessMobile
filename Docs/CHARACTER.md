# 角色模型替换说明

> 现在角色是一个**胶囊占位体**（`Player/Body`）。
> 只要把一个模型预制体放到 `Assets/Resources/PlayerModel.prefab`，运行时会自动替换，不需要改任何代码。

---

## 关于「DeepSeek 鲸鱼娘」

**结论：不能直接用，风险有两个，都是硬伤。**

| 风险 | 说明 |
|---|---|
| **IP 归属** | 鲸鱼是 DeepSeek 的品牌形象。未经书面许可把它做进商业游戏，属于商标/品牌侵权风险 |
| **模型授权** | 网上（B站/Sketchfab/ Booth）流传的"鲸鱼娘"3D 模型绝大多数是**同人作品**，作者只允许个人使用，商用作直接违反授权。而且它们往往没有可溯源的开源许可证 |

**如果你只是自己玩/学习**，风险低得多；但一旦上架（哪怕免费），就要按商业项目对待。

---

## 合法可用的三条路

### 路线 A：VRoid Studio（推荐，零成本）

1. 下载 **VRoid Studio**（免费，Windows/Mac）
2. 捏一个原创角色：蓝白配色 + 鲸鱼尾巴 + 呆毛，做出"鲸鱼娘"的感觉，但**是你的原创角色**
3. 导出 `.vrm` → 用 **UniVRM** 导入 Unity → 得到带骨骼的人形模型
4. VRoid 的授权允许你商用在自建模型上（导出时勾选相应条款）

优点：人形骨骼齐全、可直接套 Mixamo 动画；缺点：动漫风格，和写实森林不搭。

### 路线 B：CC0 低多边形资源

| 来源 | 内容 | 许可 |
|---|---|---|
| **Quaternius** | 大量低多边形人形/动物 | CC0，可商用 |
| **Kenney** | 角色包、动画包 | CC0，可商用 |
| **Mixamo**（动画） | 走/跑/跳/待机 | 免费商用，需 Adobe 账号 |

风格统一、体量小，适合手机。

### 路线 C：AI 生成 + Blender 修

Tripo / Meshy / Rodin 这类文生 3D，输入"蓝色鲸鱼女孩，低多边形，游戏角色"，导出 FBX 后用 Blender 修骨骼和 UV。

注意：**生成结果的商用权利要看平台条款**，多数付费档允许商用。

## 模型技术要求（否则换上会错位）

| 项 | 要求 |
|---|---|
| 类型 | **Humanoid** 人形骨骼（Rig 设为 Humanoid） |
| 朝向 | 面朝 **+Z**（Unity 前向） |
| 根节点 | 在**脚底**，不是腰部 |
| 高度 | 约 **1.7–1.8 米** |
| 层级 | 不透明，Layer 设为 **Player**（第 8 层，否则相机会把它当障碍物） |
| 动画 | 至少要 Idle / Walk / Run 三个状态，用 Blend Tree 按 `Speed` 混合 |

`PlayerVisual` 会自动：
- 隐藏原来的胶囊
- 把整个模型的 Layer 设成 Player
- 每帧把移动速度写进 Animator 的 `Speed` 参数（0=停，1=跑）

---

## 替换步骤

```
1. 模型拖进 Assets/Models/
2. Rig 设成 Humanoid，点 Apply
3. 建一个 Animator Controller：Idle / Walk / Run + Blend Tree（参数 Speed）
4. 把模型（含 Animator）拖成 Prefab
5. Prefab 命名为 PlayerModel，放到 Assets/Resources/
6. 运行游戏 → 胶囊自动消失，角色模型出现
```

控制台会打印：

```
[PlayerVisual] model applied: PlayerModel animator=yes
```

如果没打印，说明路径或命名不对，胶囊会保留（不会报错、不会坏档）。

## 现阶段建议

**先不要做模型。**

理由：
1. 玩法还在改（今天还在调相机和跳跃），模型换了会反复返工
2. 手机性能还没实测，人形骨骼 + 蒙皮对中端机是明显负担
3. 等玩法冻结后再做美术，一次性到位

**如果只是想先看看效果**：用路线 B 的 CC0 角色（30 分钟能跑起来），先确认动画链路是通的。
