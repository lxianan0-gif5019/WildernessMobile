### 已在 D4 改掉的一笔

角色不再走 Tripo（省下约 500 积分 / ¥35），改 VRoid 自捏或买现成模型 → **这 200 块全部给环境、建筑、武器**。

### 花法（按顺序，别跳步）

1. **300 积分** 风格探索：先出 8–10 个低档模型，把"半写实 + 轻卡通"的调子定死
2. **500 积分** 角色与怪物的身体部件（服装、护甲、武器）
3. **800 积分** 环境资产（一棵树只生一次，靠缩放/换色/换材质做变体）
4. **400 积分** 建筑与道具（能用手搓的就别花积分）
5. **留 850 积分** 当返工池，不到最后不许动

### 省积分的硬规则

- **重拓扑别在 Tripo 做**（35–40 积分/次），导出后用 Blender 的 Decimate 或 Unity 自带的减面，免费
- **动画别在 Tripo 买**，用免费素材重定向
- 建筑/箱子/地形块/UI 图标：ProBuilder + Blender，**0 积分**
- 文生 3D 只用于环境物件；角色和精细道具一律**图生 3D**（正面清晰立绘，成功率差一倍）
