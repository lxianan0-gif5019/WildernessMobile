## 2026-11-01（第 1 天）

**新增功能**

- 森林地形：600×600 米起伏地形、草地/泥土双图层、420 棵装饰树
- 第三人称角色控制：WASD 相对镜头移动、跳跃、重力、镜头环绕跟随、遮挡自动拉近
- 触屏输入：左下摇杆 + 右半屏拖动转视角 + 5 个功能按钮
- 采集：树/石/灌木可采集，砍完消失
- 背包：堆叠式物品栏，可在面板里看到数量
- 合成：木板（3 木 → 2 板）、墙（2 板 → 1 墙）
- 建造：`B` 进入建造模式，蓝色预览墙跟着镜头，`E` 放下，走近按 `E` 可捡回
- 昼夜循环：5 分钟一个完整昼夜，太阳角度/颜色/环境光/雾/天空联动
- 存档：玩家位置、背包、放下的墙、时间，写 JSON 到本地

**数据流（今天新增的三条）**

```
采集：射线命中 ResourceNode → Inventory.Add(id, n) → GameUI 每帧读 Inventory 显示
建造：BuildSystem 花 Inventory 里的 wall → 生成带 PlacedStructure 的方块
存档：SaveSystem 读 Inventory / 玩家 / 所有 PlacedStructure / timeOfDay → 写 JSON
```

**新增的调参项**

| 对象 | 组件 | 参数 | 作用 |
|---|---|---|---|
| Player | ThirdPersonController | moveSpeed / jumpHeight / turnSpeed | 移动手感 |
| Main Camera | ThirdPersonCamera | mouseSensitivity / lookSmoothing / distance / verticalSmooth | 视角手感 |
| GameManager | DayNightCycle | dayLengthSeconds / timeOfDay | 昼夜速度与起始时间 |
| GameManager | TouchRouter | stickRadius / stickDeadZone / lookSensitivity | 手机触屏手感 |
| Player | BuildSystem | range | 建造距离 |
| Player | PlayerInteractor | reach / pickupReach | 采集与拾取距离 |

- 美术全部是几何体占位，没有动画和音效

## 2026-11-02（第 2 天 · 上午）

**主题：触屏问题集中修复**

真机反馈的 5 个问题，全部找到根因：

| 现象 | 根因 | 修复 |
|---|---|---|
| 按钮点不开 | `TouchRouter` 与 `GameUI` 执行顺序不确定，点击标志在同一帧被提前清掉 | `TouchRouter` 加 `[DefaultExecutionOrder(-50)]`，先于所有消费者 |
| 点按钮时视角抖动 | 按钮没命中 → 同一根手指落进"视角区" | 按钮改为按屏幕比例定位，不再互相遮挡 |
| 摇杆区域也能转视角 | 判定区只有 240 像素，手指稍偏就出界 | 摇杆外套 400 的透明热区，可见圆仍是 240 |
| Craft / Build 重叠 | 固定像素偏移，2.18:1 宽屏纵向被压缩 | 改用归一化锚点（0.88 / 0.72 / 0.56 / 0.30 / 0.14） |
| 视角太灵敏 | `lookSensitivity = 0.16` | 改为 **0.085** |

**数据流变化**：无（只改了输入命中与 UI 布局）

**新增调参项**：`GameManager → TouchRouter → Look Sensitivity`

**已知问题**：以上修复全部待真机验证

**附**：编辑器异常退出时，用命令行构建更可靠
```
Unity.exe -projectPath <项目> -batchmode -quit -executeMethod BuildTool.BuildApk
```

**新增四条属性 + 顶部状态条**：生命 HP / 食物 FOOD / 水 WATER / 体力 STAMINA

| 数值 | 设置 | 含义 |

| 饥饿下降 | 0.18 /秒 | 满值约 **9 分钟**见底 |

**新增物品与场景物件**

**死亡与重生**：血量归零 → 1.5 秒后传回出生点，四项属性回满

**存档新增**：`health` / `hunger` / `thirst` 三个字段（存档文件向后兼容）

```

**新增调参项**：`Player → PlayerStats` 下的各项每秒变化率

## 2026-11-02（第 2 天 · 深夜）掉落拾取 + 树倒 + 窝/床

**采集方式变了**

以前：砍一下，木头直接进背包。
现在：**木头掉在地上，要走过去捡**（1.9 米内自动拾取）。

- 每次采集掉落一个可拾取物（会浮动、旋转）
- 树砍完会**倒下**（1.1 秒动画）再消失
- 掉落物带物品颜色，远远就能看出是什么

**窝和床**

| 物品 | 配方 | 耗时 |
|---|---|---|
| **干草窝** | 8 纤维 | 5 秒 |
| **木床** | 6 木头 + 4 木棍（需工作台） | 7 秒 |

**睡觉规则**

- 只能在**夜里**睡
- **18 米内有狼不能睡**（提示会说明原因）
- 睡到第二天早上 0.30，天数 +1
- 睡醒：体力回满、回 25 血、附近的狼全部消失

**数据流**

```
采集: ResourceNode.Harvest → DropLoot() → ItemPickup.Spawn()
      → 玩家靠近 1.9m → ItemPickup.Collect() → Inventory.Add
睡觉: PlayerInteractor 命中 SleepSpot → CanSleep(检查夜晚 + 狼距离) → Sleep()
      → DayNightCycle.timeOfDay = 0.30, dayNumber++
```

**已知问题**

- 掉落物不会消失，砍多了地上会堆很多
- 睡觉没有熄灯/黑屏过场（瞬间天亮）
- 工具耐久和篝火燃料还没做（下一步）

## 2026-11-02（第 2 天 · 收尾）中文化 + 引导 + 存档位 + 音效 + 菜单

**⑩ 中文化**

- 新增 `Loc.cs` 字符串表（英/中双语，约 90 条）

**⑧ 新手引导**

四步目标链，显示在状态条下方：

```
目标：砍树收集木头（3/5）
目标：合成并放下工作台
目标：合成并点燃篝火
目标：活过第一个夜晚
目标：你活下来了。接下来，活得更好。   ← 变绿
```

**⑨ 存档位**

- 3 个手动存档位 + 1 个自动存档
- 主菜单：读取存档 → 列出三个位（空/已保存）
- 暂停菜单：保存 → 选位置写入
- `SaveSystem.SaveToSlot(n)` / `LoadFromSlot(n)`，文件名 `wilderness_save_slotN.json`

**⑤ 音效（程序合成）**

脚步 / 砍树 / 拾取 / 受伤 / 狼嚎 / 狼咬 / 合成完成 / UI 点击，全部代码合成波形，无素材依赖

**⑥⑦ 菜单与设置**

主菜单（继续/新游戏/读档/设置/退出）、暂停菜单、设置 7 项（总音量/音效/视角速度/摇杆大小/画质/反转/语言）

菜单打开时 `InputHub.MenuOpen = true`：摇杆、视角、采集、建造全部失效，只有菜单按钮响应

**数据流（新增）**

```
